# 项目简介

## 核心功能
- 菜品信息推荐
- 菜品分类
- 菜品详情
- 加入购物车
- 餐桌预订
- 菜品数据可视化分析
- 用户管理
- 菜品信息管理
- 预订信息管理
- 进货信息管理
- 系统管理

## 适用场景
- 餐饮行业
- 餐饮企业管理
- 餐饮数据分析

## 技术特点
- 使用 Django 框架构建，确保系统稳定性和安全性
- 基于 MySQL 数据库，确保数据存储效率和可靠性
- 采用 Vue.js 进行前端开发，提供良好的用户交互体验
